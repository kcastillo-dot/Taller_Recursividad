# Taller de Recursividad en Java

Karen Gabriela Castillo muñoz

## Descripcion del Taller
Este repositorio contiene la solucion a un taller practico de programacion en Java enfocado en el uso de la recursividad, el programa cuenta con un menu interactivo en consola que permite ejecutar 14 ejercicios diferentes de logica matematica y manipulacion de datos sin utilizar bucles iterativos convencionales (for/while) para su logica principal. 

Entre los ejercicios resueltos se encuentran: calculo de factoriales, inversion de numeros, sumatorias, algoritmo de Euclides (MCD), operaciones por sumas/restas sucesivas, calculos sobre arreglos y matrices, serie de Fibonacci y la funcion de Ackermann.

## Instrucciones para ejecutar el programa

1. Clona este repositorio o descarga los archivos en tu computadora.
2. Abre la carpeta `Taller-Recursividad` en tu editor de codigo (como Visual Studio Code).
3. Asegurate de tener instalado el Java Development Kit (JDK) y la extension "Extension Pack for Java" si usas VS Code.
4. Navega hasta el archivo `src/Recursividad.java`.
5. Puedes ejecutar el programa de la siguiente forma:
   -(Visual Studio Code): Haz clic derecho dentro del codigo y selecciona `Run Java`, o presiona el boton de "Play" en la esquina superior derecha del editor.
